## 3. Primary Key

**Constraint:** `PK_Clinic`

**Columns:** `Id`

### Justification

- INT IDENTITY provides compact sequential clustered keys.
- Reduces fragmentation.
- Matches the project-wide primary key strategy.

## 4. Foreign Keys

None.

### Justification

Clinic is the root administrative entity.

## 5. Unique Constraints

| Constraint | Columns |
|------------|---------|
| UQ_Clinic_Email | Email |

### Decision

- Clinic email must remain globally unique.
- Email **cannot be reused** even after Soft Delete.
- SQL Server's Unique Constraint automatically creates the supporting Unique Index, so no additional index is required.

## 6. Check Constraints

None.

### Decision

Application validation (FluentValidation) is responsible for format validation. SQL Server only enforces structural integrity.

## 7. Indexes

No additional indexes.

### Notes

- `PK_Clinic` creates the clustered primary key index.
- `UQ_Clinic_Email` creates the unique index for email.
- No standalone index on `IsDeleted`.

### Justification

`IsDeleted` has very low selectivity (typically most rows are `0`), making a standalone index inefficient. If future workload analysis requires it, composite or filtered indexes may be introduced.

## 8. Navigation Properties

| Navigation | Target | Cardinality |
|------------|--------|-------------|
| Branches | Branch | One-to-Many |
| Doctors | Doctor | One-to-Many |

## 9. Business Rules

- A Clinic represents a single tenant.
- A Clinic can own multiple Branches.
- A Clinic can employ multiple Doctors.
- Every Clinic must have a unique Email.
- Every Clinic must have a valid Address.
- Soft Delete hides records but does not release unique values.

## 10. EF Core Notes

- Address mapped as an Owned Value Object.
- No Fluent API implementation in this phase.
- CreatedAt generated by SQL Server.
- UpdatedAt managed by the application.
- Global query filter for IsDeleted will be implemented later.

## 11. SQL Server Notes

- NVARCHAR for Unicode support.
- DATETIME2(3) for timestamp precision.
- INT IDENTITY for primary keys.
- BIT for soft delete flag.
